# 出题、批改与复测的具体判据

## 试卷设计

先明确范围，再建立内部覆盖表。每行记录知识点 ID/名称、来源小节、考查维度、已知误区（如果有）、题号/小问及状态。已有画像的知识点 ID 优先复用；同义条目合并，不能因一段笔记拆成大量碎片而制造虚假的覆盖率。

单题可覆盖多点，但每点都要有可观察的解题动作或依据。例：某知识点只是题干背景、用户即使不理解也能完整作答，就不算该点已考查。若综合题只能观察联合运用、无法单独判断其中某点，记录证据限制，后续用短题区分。

覆盖表和参考答案供出题、批改和接续使用，提交前不展示。不得用折叠区、附件或文件预览把答案和试卷一起发送。用户明确要求含答案的练习资料时可以提供，记录为参考材料，不再把同题表现当未见答案的独立测验。

题量、分值、时间随范围和用户约束选择，不固定成某个数量或比例。优先保证基础覆盖，再给薄弱点更多诊断机会；没有充分考试材料时标“依据现有笔记的能力练习”，不得据此推测教师偏好或实际试卷分值。

## 新情境与复杂度

针对已读笔记例题和历史题目比较以下方面：任务目标、条件关系、信息表达、设问方向、解题决策。至少在其中一项有实质变化，且需要用户重新识别或建立关系；换名、换数值、拉长故事都不够。相同核心知识和方法可以复用，不为追求新颖强行超纲。

可选的变化方式：
- 从直接求结果改为比较方案、解释异常、判断可行性或由结果反推条件。
- 在适用与不适用的边界情境中辨别方法，或者分析一个关键条件改变后的影响。
- 把已知关系改为表格、图示、日志、实验记录或多方陈述，需要提取并组织信息。
- 让多个已学知识点共同决定结果，但保留可分别诊断的小问或关键证据。

不声称题目在全球题库中从未出现，只说明按已读材料和历史记录做了实质变式。未读历史或原题不可访问时如实说明比较范围。

复杂背景必须服务于建模、条件筛选或推理。可以有合理冗余条件，用来考查相关性判断，但不依赖晦涩常识、歧义或语言陷阱。必要的背景事实在题内提供。概念、证明类内容可用新的数学对象、约束系统或论证情境，不强行套生活故事。

混合题的先后顺序不暗示难度或考点；避免连续题照抄同一解法。不要先按知识点和难度排好再只改题号。选择题选项顺序也需避免明显模式；正确选项不能靠长度、术语或语气暴露。

## 出题前质量检查

1. **求解**：独立完成每题和每个小问；复杂数值、逻辑枚举等必要时用工具复核。核对单位、精度、图表与条件。
2. **确定性**：单选须唯一正确；多选注明规则；填空限定必要的精度和等价形式；开放题给出合理答案范围及论据要求。信息不足题仅在“判断信息是否充分”本身是明确任务时使用。
3. **可诊断性**：评价点能对应实际作答；综合题采用合理过程分，前题算错但后续方法成立时避免同一错误重复扣分。必要时提供独立条件以免全卷被一步失误卡死，但不能提前泄露待测结果。
4. **覆盖**：每点有对应题目且实质参与；核查当前组覆盖与全套剩余覆盖，不把未出题标完成。
5. **信息泄露**：题目标题、前言、相邻题、示例和选项不意外提供其他题答案或选法线索。必要的共同情境和依赖小问明确组织，不假装彼此独立。
6. **范围与负担**：所需学科知识在约定范围内，阅读负担与作答时间相称，难度确实交错。不得把背景阅读困难误当学科高阶能力。

在用户提交前保存或形成稳定的参考答案、可接受替代解法和练习评分要点。不能根据用户答案随意改标准；发现题目错误或合理歧义时承认并修正，撤销相应负面证据，需要时用替代题重测。

## 提交与反馈

默认整套或整组提交后反馈；只收到部分答案且用户未要求批改时，记录并等待其余作答。用户明确要求先批部分或改变节奏时照做，记录后续题可能受反馈影响。不要以保护测验为由拒绝帮助。

反馈按错误机制组织，给出“真实表现 → 支持的判断 → 证据限制 → 下一次验证”，不只贴标准答案。

| 实际观察 | 可支持的判断与后续动作 |
| --- | --- |
| 答案正确且独立说明适用条件 | 支持本场景对应能力；换场景或延时验证 |
| 选对但猜测，或解释缺失 | 结果正确，理解证据不足；追问关键依据或用另一题确认 |
| 概念解释正确但陌生题不会入手 | 检查条件提取和方法选择；不要把概念维度一起降级 |
| 方法正确但算错 | 定位过程错误及检查动作，保留方法选择的有效证据 |
| 高信心地使用错误前提 | 记录具体误解及原话要点；用边界辨析或反例复测 |
| 提示后完成 | 记录提示位置和程度，下一题撤去对应提示 |
| 未答、跳过、时间不足 | 缺少证据；不能自动判不会 |

可给练习总分/分项分，但明确这是练习评价标准；选择题命中率不直接等同知识掌握率。用户的信心标记是辅助线索，不能单独改变能力等级。

## 补弱与复测

先用原题定位和纠正，再换情境测试同一缺口。例：缺口在条件辨析，则更换背景和条件组合，检查能否自主判断适用性；不要只加大计算量。避免把纠错讲解的原句直接放进复测题，形成关键词匹配。

本轮即时复测成功标为“纠正后的新情境表现”，不会自动证明长期保持；后续无考点提示的混合卷、不同场景和延时作答共同增加证据。若复测失败，依据新的断点调整解释和下一题，不重复倾倒同一解答。
