# v0.2.0 · 术语覆盖、规范答案与分段讲练

本次更新 `semester-study-coach`，根据实际考试学习反馈补齐术语、答案表述、讲练节奏和题型搭配。`obsidian-review-coach` 的独立测评流程保持原样。

## 主要变化

- 核对 PPT 红字、加粗、定义、缩写及必要专有名词，记录来源与讲解/练习状态。
- 用易懂语言解释后，再提供专业、严谨的正式答案；有官方答案时注明来源，否则提供规范参考答案。
- 主观题做错或回答不完整时，必须给出完整规范参考答案与必要步骤；客观题给正确答案和理由。
- 记忆型每两个到三个小阶段练习，逻辑计算型每阶段练习，混合课程按内容切换；保留答疑空间。
- 客观题∶主观题默认约 1∶3，可调为 1∶2，按练习组或连续几轮累计；后续阶段穿插旧知识短复测。
- 接续记录补充课程模式、阶段边界、术语待补项与题型进度，不重置旧画像。
- 补齐 `.gitignore` 与跨平台 CI，保留现有首次配置、安装工具和 MIT 许可证。

## 更新方式

保留本地 `semester-study-coach/state/`，按原路径合并新方法文件。本次不需要重新初始化、迁移学习记录或重装另一 skill。详见 README 和 `docs/PUBLISHING.md`。

## 验证范围

本次在本地 macOS 验证发布结构、skill 格式与既有辅助脚本行为测试。其他平台以本次提交的 GitHub Actions 实际结果为准；这些检查不代表教学效果或模型答案正确性已得到全面验证。

发行文件不包含真实个人学习记录。
