# v0.2.1 · 小组复习、规范答案与笔记分离

本版改进笔记复习教练的练习负担、题型安排、答案讲解及 Obsidian 笔记整理。

- 每轮默认 **4—5 道题**，前置诊断、旧知识回顾和即时复测共用题量预算，同时限制小问数量、阅读量和预计耗时。范围较大时分轮覆盖。
- **课程题型要求优先**：严格遵循已明确的题型、比例和分区；没有明确要求时组合多种适宜题型，避免长期只有简答题。
- **先通俗解释，再给完整规范参考答案**：客观题给正确答案和依据，主观题提供完整要点或必要推导步骤，区分教师/官方答案与自编参考解答。
- **知识笔记与教练记录分开**：知识笔记保留概念、条件、方法、通用易错提醒和必要例题；个人作答、提示和复测表现由独立教练索引定位到原有会话与唯一画像。
- 保持既有学科路由和状态格式，课程带学教练的教学规则及组件版本不变。

## 已安装用户

合并新版 `skills/obsidian-review-coach/` 中的方法文件到本地同名 skill 目录，保留 `semester-study-coach/state/` 及个人文件。无需重新初始化或迁移能力画像；新版规则在后续复习和整理时使用。
